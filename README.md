# 💬 委婉拒絕小工具（POC）

> 第九組 · 上週全組腦力激盪選出的最小可行 POC。

## 這個 POC 做什麼

這是一個「委婉拒絕」輔助工具。員工面對主管或上層提出的**不合理要求／指示**時，
常常不知道怎麼開口拒絕，或不確定怎麼說才不會傷了關係、又能守住自己的立場。

本工具把拒絕的過程拆成 4 個步驟，幫員工：

1. **描述**主管提出的要求；
2. **選擇**拒絕的最主要理由（並可提供替代方案）；
3. **選擇**語氣（禮貌委婉 / 中性專業 / 明確堅定）；
4. **一鍵生成**一封完整、得體的回覆草稿，可直接複製使用。

## 給誰用

- **使用者：員工**（一般職員、工程師、行政人員……）。
- 使用場景：當主管交辦不合理要求時（例如時間不足、工作量超載、超出職權範圍）。
- 設計精神：**委婉但不委屈**——拒絕的同時，仍展現配合意願與專業態度。

## 怎麼用

### 1. 遵循（最簡單）
用瀏覽器直接開啟 `index.html` 即可，**不需要安裝、不需要 build**。

- 直接用滑鼠**雙擊** `index.html` 檔案；
- 或在瀏覽器網址列輸入檔案路徑：`file:///E:/USER/桌面/1027/index.html`。

### 2. 操作步驟
1. 在「步驟 1」把主管的要求貼進文字框（可先按「填入練習範例」看示範）；
2. 在「步驟 2」選擇拒絕理由，並（選擇性）填寫替代方案；
3. 在「步驟 3」選語氣；
4. 按「生成回覆草稿」，即可看到結果並複製。

> 本工具**完全在瀏覽器本地運行**，資料不會傳出你的電腦。
